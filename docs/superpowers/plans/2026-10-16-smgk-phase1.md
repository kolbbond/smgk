# smgk Phase 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A persistent smg window that watches a project's Jupyter kernel and shows every cell's code, text, errors and plots, while a recorder saves the session as `.ipynb` and a `smgk` CLI lets nvim, the agent and C++ codes drive and feed it.

**Architecture:** One ipykernel per project (git root, else cwd) with state in `<root>/.smgk/`. A Python package `smgk` owns kernel lifecycle, the recorder (sole `.ipynb` writer) and the push/note/run helpers. A C++ app `smgk-view`, linking installed smg, subscribes to the kernel's IOPub over ZeroMQ, loads recorded history first, then follows live. nvim gets a separate key that starts the kernel and opens `jupyter console --existing` in the slime pane.

**Tech Stack:** C++17, CMake + Ninja, smg (Magnum + ImGui), libzmq 4.3.5 + cppzmq 4.10.0 + nlohmann_json 3.11.3 + stb_image (all via FetchContent, pinned); Python 3 with jupyter_client 8.8, ipykernel 7.1, nbformat 5.10, pytest 8.1; Lua (nvim-config).

**Spec:** `docs/superpowers/specs/2026-10-16-kernel-viewer-design.md`

## Global Constraints

- Repo is `~/programs/cpp/smgk`; **no changes to smg** without asking the user first.
- smg is consumed via `find_package(smg)` from an installed prefix: `~/.local/opt/smg`.
- C++ style: LLVM base, 4-space indent, 140 columns, no tabs, compact namespaces, short blocks/functions/ifs on one line, pointer left (`int* p`), includes not sorted. Run `clang-format -i` on every C++ file touched.
- Per-project state dir name: `.smgk/`; files `kernel.json` (connection), `state.json`, `recorder.ready`, `*.log`.
- Notebooks: `<root>/notebooks/<YYYY-MM-DD>-<HHMMSS>.ipynb`, nbformat 4, one per kernel start.
- Kernel python: `$VIRTUAL_ENV/bin/python` when `VIRTUAL_ENV` is set, else `sys.executable` of the CLI. Missing ipykernel → exit 2 with message `ipykernel is not installed in <python>; run: <python> -m pip install ipykernel`.
- Cell metadata key: `metadata.smgk = {"msg_id": <parent msg_id>, "kind": "cell"|"run"|"push"|"note"}`.
- Helper-originated executes use `Session(username="smgk")`; push/note executes use `silent=True, store_history=False`.
- Viewer closed/crashed must never affect kernel, console or recorder.
- Existing nvim ipython flow (`<leader>vp`, `<leader>hp`) must behave exactly as before.
- Commits: topic-prefixed, laconic (`view: ...`, `cli: ...`), no Co-Authored-By trailer.

## Review Focus

1. **Viewer opened mid-session** — history loads once; no duplicated or missing cells at the load/live seam. Test in Task 6 (`test_feed_dedupe`).
2. **Kernel restart while the viewer is open** — viewer clears, reconnects to the new generation, shows the new notebook; no crash or stale cells. Test in Task 7 (`test_view_restart`).
3. **Multi-line indented cells sent by slime to `jupyter console`** — the whole block runs (no hanging `...:` prompt). Check in Task 8, step 4.
4. **Errors with ANSI-colored tracebacks** — readable plain text, no escape garbage. Test in Task 5 (`test_ansi`).
5. **Helper used with no kernel running / outside any project** — clear one-line error, nonzero exit, no hang. Test in Task 4 (`test_push_no_kernel`).

### Task 3: Recorder — complete `.ipynb` from IOPub

**Files:**
- Create: `python/smgk/recorder.py`, `python/tests/test_recorder.py`
- Modify: `python/smgk/kernel.py` (start/stop recorder)

**Interfaces:**
- Consumes: `kernel.State`, `kernel.connect`.
- Produces:
  - `recorder.NotebookBuilder`: `apply(msg: dict) -> bool` (True when the notebook changed), `notebook() -> nbformat.NotebookNode`.
  - Process: `python -m smgk.recorder <root>`; writes `.smgk/recorder.ready` once subscribed; rewrites the notebook atomically on every `status: idle`; exits when the kernel pid is gone.
- Mapping (by `parent_header.msg_id`):
  - `execute_input` → code cell, `source`, `execution_count`; kind `run` if `parent_header.username == "smgk"` else `cell`.
  - `stream`/`execute_result`/`display_data`/`error` → nbformat outputs on that cell; if no cell exists for the parent (silent request), create one: kind = `content.metadata.smgk.kind` (`push` → code cell, empty source; `note` → **markdown** cell whose source is the `text/markdown` data, no outputs).
  - consecutive `stream` with same `name` merge into one output.
- Ready handshake: after subscribing, the recorder sends its own `kernel_info_request` and waits for an IOPub `status` whose parent is that request (proves SUB is live), then touches `recorder.ready`. `kernel.start` waits up to 10 s for it, else exits 1 with `recorder failed to start, see .smgk/recorder.log`.

### Task 5: C++ core model — wire parsing, feed, ANSI

**Files:**
- Create: `src/Wire.hh/.cpp`, `src/Feed.hh/.cpp`, `src/Ansi.hh/.cpp`, `test/test_wire.cpp`, `test/test_feed.cpp`, `test/test_ansi.cpp`, `test/fixtures/*.json`

**Interfaces:**
- Produces (namespace `smgk`):
  - `struct Msg { std::string msg_type, msg_id, parent_msg_id, username; nlohmann::json content, metadata; };`
  - `std::optional<Msg> parse_wire(const std::vector<std::string>& frames);` — frames after the `<IDS|MSG>` delimiter are signature, header, parent_header, metadata, content; signature not verified (local trust); missing delimiter or bad JSON → `nullopt`.
  - `struct Output { enum class Kind { Stream, Text, Image, Error }; Kind kind; std::string text; std::string png_b64; std::string name; };`
  - `struct Cell { std::string msg_id, kind; int exec_count = -1; std::string source; bool markdown = false; std::vector<Output> outputs; };`
  - `class Feed { public: bool apply(const Msg&); void load_notebook(const nlohmann::json& nb); void reset(); const std::vector<Cell>& cells() const; const std::string& status() const; };` — same grouping/kind rules as the recorder (Task 3); `apply` ignores messages whose parent `msg_id` came from `load_notebook` **and** whose type is `execute_input` (dedupe), and appends outputs only if not already present for a loaded cell (compare by count: skip if the loaded cell already has ≥ that many outputs).
  - `std::string strip_ansi(std::string_view);` — removes CSI sequences `ESC [ ... final-byte`.
  - Error output `text` = `strip_ansi(join(traceback, "\n"))`.
